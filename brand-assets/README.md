# VisionaryAds brand assets

Portable logo files, for use anywhere off the website (social profiles, documents, signatures, printed materials). These live outside `public/` on purpose — they're not part of the deployed site, just source assets for you.

| File | Use it for |
|---|---|
| `visionaryads-logo-for-dark-backgrounds.png` | Full wordmark, light text — use on dark surfaces (matches the site itself) |
| `visionaryads-logo-for-light-backgrounds.png` | Full wordmark, dark text — use on white/light surfaces (documents, letterhead) |
| `visionaryads-icon-square.png` (512×512) | Icon only, no wordmark — profile pictures (Instagram, LinkedIn, Facebook Page, etc.) |

**A real limitation to know about:** these are high-resolution PNGs (raster), not vector artwork. They'll look sharp anywhere digital, including most print sizes, but they aren't infinitely scalable the way a true vector logo (AI/EPS/SVG with outlined text) would be. If you ever need this on a sign, a vehicle wrap, embroidery, or anything printed very large, that calls for a proper vector logo file — a different, more involved job than this one.

All three use the exact same colors and typeface (Saira) as the live site, so they'll always match.
